# 数据指标与计算公式

> 配套 PRD 主文档使用。覆盖"数据概览"页面的所有字段定义、计算公式、数据来源。

## 1. 总览层(4 张卡)

### 1.1 素材总数 `totalCount`
- **公式**:`COUNT(*) WHERE status NOT IN ('DELETED')` 或 `COUNT(*) WHERE deleted_at IS NULL`
- **来源**:`GET /open_api/2/file/material/stats/total`
- **环比**:`(today_total − yesterday_total) / yesterday_total × 100%`

### 1.2 今日新增 `todayCount`
- **公式**:`COUNT(*) WHERE createTime >= today_start AND createTime < tomorrow_start`
- **来源**:同 `material/stats` 接口
- **环比**:`(today_new − yesterday_new) / yesterday_new × 100%`,正涨绿、负跌红

### 1.3 有效素材 `validCount`
- **公式**:`COUNT(*) WHERE audit_status = 'PASS' AND status = 'VALID'`
- **来源**:同 `material/stats`,字段 `valid`
- **占比副文本**:`validCount / totalCount × 100%`(前端派生 `validRatio`)

### 1.4 待处理素材 `pendingCount`
- **公式**:`COUNT(*) WHERE audit_status IN ('PENDING', 'AUDITING')`
- **来源**:同 `material/stats`,字段 `pending`
- **细分**:PENDING(待预审)+ AUDITING(审核中)

## 2. 合规质量层(3 张卡)

### 2.1 预审通过率 `passRate`
- **公式**:
  ```
  SUM(CASE WHEN audit_status='PASS' THEN 1 ELSE 0 END)
  ─────────────────────────────────────────────────────  × 100%
  COUNT(CASE WHEN audit_status IN ('PASS','REJECTED') THEN 1 END)
  ```
- **时间窗**:近 7 天
- **来源**:`GET /open_api/2/file/material/audit/passRate?range=7d`
- **环比**:与上一周期对比

### 2.2 平均质量评分 `avgQuality`
- **公式**:`AVG(quality_score) WHERE audit_status = 'PASS'`
- **来源**:`GET /open_api/2/file/material/quality/avg`
- **取值**:0–100,含 clarity / brightness / contrast 三个子维度

### 2.3 不合规素材 `rejectCount`
- **公式**:`COUNT(*) WHERE audit_status = 'REJECTED' OR status = 'WARNING'`
- **来源**:`GET /open_api/2/file/material/audit/nonCompliant`
- **预警**:>0 即标红

---

## 3. 资产活跃层(3 张卡)

### 3.1 活跃素材(7 日) `activeCount`
- **公式**:`COUNT(DISTINCT material_id) WHERE creative_id IS NOT NULL AND consume_time >= now() - 7d`
- **来源**:`GET /open_api/2/file/creative/activeMaterials?range=7d`
- **占比**:`activeCount / totalCount × 100%`(前端派生 `activeRatio`)

### 3.2 闲置素材(30 日) `idleCount`
- **公式**:`COUNT(*) WHERE status = 'VALID' AND (last_used_time IS NULL OR last_used_time < now() - 30d)`
- **来源**:`GET /open_api/2/file/material/idle?days=30`
- **业务价值**:清理候选,与"素材清理"模块联动

### 3.3 总消耗 `totalCost`
- **公式**:`SUM(material.cost) WHERE createTime >= now() - 7d`,素材粒度累加
- **来源**:`GET /open_api/2/file/creative/stats/totalCost?range=7d`
- **单位**:元,千分位格式化

---

## 4. 团队运营层(2 张卡)

### 4.1 活跃成员(7 日) `activeMembers`
- **公式**:`COUNT(DISTINCT user_id) WHERE action IN ('upload', 'audit', 'create_creative') AND time >= now() - 7d`
- **来源**:`GET /open_api/2/file/user/active?range=7d`
- **环比**:0 时显示"持平"

### 4.2 需求完成平均时长 `avgRequirementHours`
- **公式**:`AVG(requirement_complete_time − requirement_create_time) / 3600` WHERE `status = 'COMPLETED'`
- **时间窗**:近 7 天
- **单位**:小时
- **来源**:`GET /open_api/2/requirement/avgCompleteDuration?range=7d`
- **环比**:变短即降本增效(绿),变长即恶化(红)

---

## 5. 图表层(6 张图)

### 5.1 上传趋势(双轴折线)
- **X 轴**:最近 N 天(`7 / 14 / 30` 单选切换)
- **左 Y 轴**:数量 `COUNT(*) GROUP BY DATE(createTime)`
- **右 Y 轴**:体积 `SUM(size) GROUP BY DATE(createTime)` 单位 GB
- **来源**:`GET /open_api/2/file/material/uploadTrend?days=N`
- **特殊处理**:周末基础量按 30% 降权

### 5.2 状态分布(环形)
- **公式**:`COUNT(*) GROUP BY status`,5 段:有效 / 待预审 / 审核中 / 已拒绝 / 已下架
- **来源**:`GET /open_api/2/file/material/stats/status`
- **中心文本**:`totalCount`

### 5.3 审核转化漏斗
- **4 步转化**:
  ```
  素材总数 → 提交预审(待预审 + 审核中) → 审核通过 → 已投放使用(活跃素材)
  ```
- **来源**:复用 stats 接口字段,前端组装

### 5.4 素材点击率分布(直方图)
- **公式**:`COUNT(*) GROUP BY bucket(ctr)`,按 ctr 5 档分桶
- **5 档**:
  | 区间 | 等级 | 颜色 |
  |---|---|---|
  | 0 – 0.5% | 低 | 灰 |
  | 0.5% – 1% | 偏低 | 橙 |
  | 1% – 2% | 合格 | 绿 |
  | 2% – 5% | 良好 | 蓝 |
  | 5% + | 优秀 | 紫 |
- **来源**:`GET /open_api/2/file/creative/ctr/distribution?range=7d`
- **数据源**:巨量引擎 ctr 字段,前端派生分桶

### 5.5 Top10 热门(横向条形)
- **公式**:`SELECT * FROM material ORDER BY total_cost DESC LIMIT 10 WHERE consume_time >= now() - 7d`
- **来源**:`GET /open_api/2/file/material/top?orderBy=cost&range=7d&limit=10`

### 5.6 存储使用趋势(面积图)
- **公式**:按日聚合 `SUM(size)`,展示最近 7 天累计已用容量(GB)
- **来源**:`GET /open_api/2/file/storage/usage?days=7`
- **markLine**:1024 GB 容量上限,红色虚线告警

---

## 6. 列表层(2 张)

### 6.1 即将到期素材
- **公式**:`SELECT * WHERE expire_time BETWEEN now() AND now() + 30d ORDER BY expire_time ASC LIMIT 6`
- **来源**:`GET /open_api/2/file/material/expiring?days=30`
- **分级**:`days ≤ 7` 紧急(红),`7 < days ≤ 30` 即将到期(橙)

### 6.2 最近上传(表格)
- **公式**:`SELECT * ORDER BY createTime DESC LIMIT 10`
- **来源**:`GET /open_api/2/file/material/list?orderBy=createTime&limit=10`
- **状态映射**:`VALID→审核通过 / PENDING→待预审 / AUDITING→审核中 / REJECTED→审核失败 / DELETED→已下架`

---

## 7. 派生指标(前端计算)

| 字段 | 公式 | 位置 |
|---|---|---|
| `validRatio` | `validCount / totalCount × 100`,保留 1 位小数 | 有效素材副文本 |
| `activeRatio` | `activeCount / totalCount × 100`,保留 1 位小数 | 活跃素材副文本 |
| `formatSize` | 自动转 B / KB / MB / GB / TB | 存储条、表格大小列 |
